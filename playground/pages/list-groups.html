Accessibility notes

  • Plain lists are <ul>/<li>; action items are real <a> (navigation) or <button> (actions) — no clickable divs, no unnecessary ARIA.
  • Active state is solid indigo + white text and aria-current="true" on navigation items — never color alone. Disabled items are muted with pointer-events: none and tabindex="-1" (not keyboard-reachable).
  • Action items get the global indigo :focus-visible ring (2px solid) plus the tertiary hover surface — keyboard focus is always visible.
  • Icons are decorative (aria-hidden); text carries names and meaning. Badges are existing Bootstrap badges — ms-auto aligns them, text stays adjacent for screen readers.
  • Numbered lists are a real <ol> with CSS counters — the numbering is generated, never typed into the item text.
