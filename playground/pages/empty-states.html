Empty vs error vs loading

Three different situations, three different presentations. An empty state never hides an error, and never appears while content is still loading.

Empty

Data loaded — there are no records. The user can create or clear filters.

Error

Data could not be loaded. Treated as an error — never shown as "empty".

Loading…

Loading

Data is being retrieved. The empty state waits until loading completes.

Accessibility notes

  • Hierarchy: decorative icon → h3 title (the primary textual anchor) → concise description → single obvious action.
  • Icons are decorative (aria-hidden="true") — the title and description carry the meaning; there are no icon-only empty states.
  • An ordinary empty state is not an alert — no role="alert" anywhere on this page. Urgency is reserved for errors.
  • Actions are real .btn buttons, keyboard-focusable with the global indigo ring; the empty table keeps its semantics via a colspan row.
  • Contrast: muted icon and description use --bs-secondary-color/--bs-body-secondary (≈8.5:1 on white); the title uses body text. Empty states are calm by design — muted but readable.
