Application Sidebar

The .mu-sidebar component — static enterprise navigation filling the .mu-app-side slot of the application shell.

Structure

  • Semantic: <aside> landmark containing a labeled <nav> landmark
  • Groups: section labels (Workspace / Management / System) with item lists
  • Active item: Dashboard — solid indigo pill, weight 600, aria-current="page" (static, no JS)
  • Badges: Bootstrap .badge + text-bg-*, positioned right with .mu-sidebar-badge
  • Nested: Bootstrap Collapse groups — the Projects toggle expands/collapses its children (chevron rotates); group toggles use data-bs-toggle="collapse"
  • Disabled: real <button disabled> — native semantics, no ARIA
  • Icons: Lucide, decorative (aria-hidden) — link text carries the name

Behavior notes

  • Width is the $mu-sidebar-width token (16rem / 256px); collapsed = $mu-sidebar-width-collapsed (4.75rem / 76px) — sized from the icon grid (2 × 38px centerline) so collapsed and expanded icons share one column and never shift
  • Surface is Bootstrap's subtle surface token — quiet, dark-theme-ready
  • The sidebar scrolls independently when the navigation list is long
  • Hover = subtle slate surface (never on disabled items); focus = the global solid-indigo outline
  • Collapse (desktop only, ≥768px): click the panel-left button in the navbar actions — labels visually hide but stay in the accessibility tree
  • Mobile drawer (<768px): the menu button opens a slide-in drawer with a backdrop; Escape, backdrop click, or the x button closes it and focus returns to the trigger
  • No persistence, no tooltips yet

Not implemented yet (later tasks)

  • Tooltip/flyout for collapsed items (nested groups are hidden while collapsed)
  • State persistence, active-route detection, dynamic navigation

Try it on desktop: collapse with the panel-left button. Shrink the window below 768px: the menu button opens the drawer; Escape / backdrop / x close it and keyboard focus returns to the trigger. The disabled “Templates” item is skipped by the keyboard.
