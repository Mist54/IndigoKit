Offcanvas

Bootstrap's .offcanvas with IndigoKit styling — white surface, hairline border, small elevation, Bootstrap's own JS (focus management, Escape, backdrop, scroll lock). Offcanvas is for temporary side panels: mobile navigation, filters, contextual settings. The desktop sidebar is a persistent shell element — this page never replaces it.

Left offcanvas

.offcanvas-start — the classic side drawer for navigation, details, or context panels. A real header with a titled heading and a close button; the body scrolls independently.

Right offcanvas — filter panel

.offcanvas-end (always a drawer) for a contextual filter panel built from the existing form system — no filtering logic.

Top & bottom

Bootstrap's directional variants, demonstrated where they are genuinely useful — a top notification bar and a bottom quick-actions sheet.

Mobile navigation

A start-aligned offcanvas holding the same navigation links the shell sidebar uses — one navigation system, presented in a drawer on mobile. No second nav API.

Long content & scrolling

The body scrolls independently; the header stays pinned. Bootstrap's scroll lock keeps the page behind still.

Accessibility notes

  • Every offcanvas has a titled heading (.offcanvas-title + aria-labelledby) as its accessible name, a real .btn-close with aria-label="Close", and Bootstrap-managed aria-hidden/role="dialog" semantics.
  • Focus: Bootstrap moves it into the panel on open and restores it to the trigger on close; Escape closes; the backdrop click closes — all stock, no custom focus manager.
  • Body scroll locks while open and restores on close; the panel content scrolls in its own region (long panels verified).
  • Offcanvas vs sidebar: offcanvas = temporary, dismissible, overlay panels (mobile nav, filters, contextual settings). The sidebar = the persistent desktop shell navigation. Use each where it belongs.
