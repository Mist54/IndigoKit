Keyboard & focus

Breadcrumb links are real anchors — Tab moves through them and the global IndigoKit focus ring (strong indigo) marks the focused link. The current page is not a link, so it is not keyboard-reachable.

Accessibility notes

  • Breadcrumbs live in a <nav> landmark with an accessible name (aria-label="breadcrumb").
  • The current page uses aria-current="page" and is not a link — only real ancestors are anchors.
  • The / separator is generated by Bootstrap's CSS (::before content) — no icon elements per item.
  • The current page is distinguished by muted color and stronger weight, never color alone.
  • Breadcrumbs are supporting navigation — the page title and primary nav remain the main orientation cues.
