Tables

Bootstrap's .table API with IndigoKit refinement — semantic markup, hairline borders, a weighted header (600, the one IndigoKit addition), token-wired striped/hover/active states, and Bootstrap's .table-responsive for overflow. No table framework, no sorting engine.

Jump links are plain anchors to the section headings — no page script needed.

Basic table

A caption describes the table; th scope="col" marks column headers. The header row is the only place IndigoKit styles th (weight 600 + emphasis color).
