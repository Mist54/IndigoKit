Cards

Bootstrap's card API with IndigoKit refinement — every section below uses standard Bootstrap classes (.card, .card-header, .card-body, .card-footer, .card-title, .card-subtitle, .card-text, .card-link, .card-img-top, .card-group). The only mu-* card class is .mu-card-interactive for interactive cards.

Interactive

Interactive cards are real links — keyboard-focusable, with the global focus ring around the card. .mu-card-interactive adds a subtle hover (indigo-tinted border + XS shadow). Static cards get no hover.
