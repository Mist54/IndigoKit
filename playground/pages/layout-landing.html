Enterprise UI, built on Bootstrap

IndigoKit is a Bootstrap-first design system with light and dark themes, measured accessibility, and a reusable application shell. Familiar API, refined visuals.

Why IndigoKit?

Built for teams that need a polished, accessible enterprise UI without rewriting everything from scratch.

Bootstrap First

Standard Bootstrap classes are the API. No parallel component system to learn.

Light and Dark

System, light, and dark themes with token-driven contrast — measured, not assumed.

Accessible

Keyboard navigation, focus indicators, ARIA patterns, and contrast verified in the browser.

Responsive

Tested from 320px to 1440px. Shell, sidebar, tables, charts — all adapt cleanly.

Optional Integrations

Chart.js and Select2 are optional — install only what you need. Core stays framework-free.

Enterprise Ready

Application shell, sidebar, nested nav, profile dropdown, and notifications — production patterns.

Designed for developers

IndigoKit extends Bootstrap's existing API rather than replacing it. If you know Bootstrap, you already know IndigoKit. The visual refinements happen underneath — tokens, shadows, radius, contrast — not through a parallel component system.

  • Standard .btn, .card, .table classes work out of the box
  • SCSS source with design tokens for easy customization
  • Optional Chart.js and Select2 integrations
  • Light/dark theme support via Bootstrap's native mechanism

Quick start

npm install indigokit

/* In your CSS */
@import "indigokit/dist/css/indigokit.css";

/* In your HTML */
<link rel="stylesheet" href="indigokit/dist/css/indigokit.css">

Bootstrap is a peer dependency. IndigoKit compiles Bootstrap's CSS with its own design tokens — no duplicate framework.
