Keyboard interaction

Bootstrap's Tab JavaScript implements the ARIA tabs pattern: →/← (and ↑/↓) move to the next/previous tab and activate it; Home/End jump to the first/last; disabled tabs are skipped; focus stays on the tab list (hidden panels are display: none, never keyboard-reachable). aria-selected and the roving tabindex are managed by Bootstrap — try it on any example above.

Accessibility notes

  • Tabs that switch content use <button>; use <a> only when the tab changes the URL (navigation).
  • Each tab links its panel with aria-controls; each panel is named by its tab via aria-labelledby.
  • aria-selected reflects the active tab; inactive tabs are removed from the tab order (roving tabindex).
  • Icons are decorative (aria-hidden="true"); the label text is the accessible name.
  • Active state is communicated by shape, weight and position — never by color alone.
