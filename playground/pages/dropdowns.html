Keyboard interaction

Bootstrap's dropdown JavaScript handles the full keyboard model: Enter/Space toggles; ↓/↑ move between items; Esc closes and returns focus to the toggle; Tab closes and moves on. aria-expanded is kept accurate by Bootstrap — try it on any menu above.
