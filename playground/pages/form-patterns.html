Form patterns

Reusable form compositions — a multi-step wizard and a file-upload list — built from Bootstrap classes and a small vanilla demo script.

Both patterns follow the same rules: label first, clear grouping, helpful validation, and no placeholder-as-label. The wizard uses Bootstrap tabs for step switching with native constraint validation on each step; the uploader renders a file list you can review and remove before submitting. No backend — the submit handlers only demonstrate the flow.
