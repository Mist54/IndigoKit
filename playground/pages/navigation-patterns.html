Navigation patterns

Existing Bootstrap/IndigoKit navigation components composed into realistic enterprise patterns — the navbar, breadcrumbs, tabs/pills, dropdowns, pagination, offcanvas, and scrollspy. No new navigation APIs.

Accessibility notes

  • Every navigation system keeps its landmark and name: the navbar is <nav aria-label="Main navigation">, breadcrumbs are a <nav aria-label="breadcrumb"> with aria-current="page", pagination is a <nav> with its own label, and the settings/spy nav has aria-label too.
  • Active states never rely on color alone: tabs/pills use weight + notch/pill shape + aria-selected, breadcrumbs use weight + muted + aria-current, pagination uses the solid indigo fill + aria-current.
  • Tabs vs pills: tabs switch related content panels (roving tabindex + arrow keys from Bootstrap's Tab JS); pills mark filter-style choices. Neither is used as decoration.
  • The dropdown is Bootstrap's own — keyboard (Space/Enter opens, arrows move, Escape closes + focus returns), focus ring, and accessible item names all stock.
  • Mobile: the navbar menu button opens the offcanvas drawer with the same section links (see the offcanvas demo on mobile). No second navigation framework.
  • Headings stay in order across every pattern (h1 page title → h2 sections → h3 panes), and no redundant ARIA is added.
