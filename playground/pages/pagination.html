Accessibility notes

  • Pagination lives in a <nav> landmark with a specific accessible name (e.g. aria-label="Search results pages").
  • The current page is a real link with aria-current="page"; it is also visually obvious via the solid indigo fill (never color alone).
  • Disabled Previous/Next are <span class="page-link"> — no href, so they are not links and not keyboard-reachable.
  • The ellipsis is a non-focusable <span> — informational only.
  • All page controls are real <a href> links with normal browser keyboard behavior (Tab / Shift+Tab / Enter) and the global focus ring.
  • Optional chevron icons are decorative; the Previous/Next text remains the accessible label.
