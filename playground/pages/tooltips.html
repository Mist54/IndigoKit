Tooltips

Bootstrap's tooltip API with IndigoKit refinement — data-bs-toggle="tooltip", data-bs-title, data-bs-placement, and Bootstrap's Tooltip JavaScript. IndigoKit initializes the triggers centrally from dist/js/indigokit.js; there is no second tooltip engine.

Accessibility note: tooltips supplement labels — they never replace accessible names. Every icon-only control below has its own aria-label; the tooltip only adds context.

Basic and placement

Icon buttons (navbar pattern)

Each icon button keeps its own aria-label — the tooltip is supplementary context, exactly as in the application navbar.

Text button

Longer tooltip

Tooltips cap at 200px (--bs-tooltip-max-width) and wrap — keep tooltip text short; longer explanations belong in visible UI.

Keyboard activation

Bootstrap tooltips show on Tab focus as well as hover — press Tab onto any tooltip button above to see the tooltip. Esc dismisses it.

Collapsed-rail pattern

A collapsed icon rail is the natural home for supplementary tooltips. The real collapsed sidebar (Sidebar showcase) already keeps accessible names via visually-hidden text; wiring its icons to tooltips is future work — the pattern is the same as here.

Disabled control

Tooltips can't attach to genuinely disabled controls (they don't fire pointer events). Bootstrap's documented pattern: a wrapper with tabindex="0" carries the tooltip while the button stays disabled.
