Long content

This alert demonstrates long-form content. Text wraps naturally at every viewport width, the icon (when present) stays top-aligned, and there is never horizontal overflow. Enterprise systems regularly surface multi-line messages like this one — imported records, retry summaries, or bulk-operation results — so alerts must remain readable and calm even when the message runs on.

Semantic usage

Static informational alerts carry no role — they are ordinary content and should not interrupt screen readers. role="alert" is reserved for messages that genuinely need immediate announcement (an operation result rendered after an action), which is exactly how the examples above are annotated. For a region that updates silently over time (e.g. a status panel), aria-live="polite" is the appropriate pattern.
