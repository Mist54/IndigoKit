Application Shell

The canonical IndigoKit shell — the real navbar and sidebar inside the reusable .mu-app layout, with collapse and the mobile drawer wired up.

Shell behavior

  • Scrolling: only .mu-app-main scrolls — navbar and sidebar stay fixed
  • Collapse (desktop ≥768px): the panel-left button narrows the sidebar to icons and main gains the space
  • Mobile (<768px): the menu button opens the drawer with a backdrop; Escape, the backdrop, or x closes it and focus returns to the trigger
  • Bootstrap compatibility: containers, rows, columns, and utilities keep working inside the shell
