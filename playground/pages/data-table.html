Data table

A full pattern: filtering, sorting, selection, bulk actions, pagination, and explicit loading / empty / error states — built only from Bootstrap classes and a small vanilla demo script.

The four table states — data, loading, empty, and error — are separate renderings, never guesses. Loading means the system is retrieving data; empty means data loaded but there is nothing to show; error means the operation failed and tells the user what to do next. Try the state switcher, then sort columns, search, select rows, and use the bulk bar.
