Application Navbar

The first IndigoKit component: .mu-app-navbar — an application-level navbar extending Bootstrap's .navbar.

Structure

  • Brand — indigo icon mark (logo placeholder) + wordmark, links to app home
  • Main area — flexible center region reserved for future breadcrumbs / search / context
  • Actions — notification and help icon buttons (placeholders only) + user/profile area

Behavior notes

  • Compact enterprise height (~4px vertical padding, no hard-coded height)
  • Surface is the page background with a subtle bottom border — no shadow in the app shell
  • On small screens the user name hides; brand and action buttons remain
  • Icons render via the approved Lucide library (lucide.createIcons(), no bundler)
  • The sidebar is a real component too (Task 006): desktop collapse (Task 008) + mobile drawer (Task 009) are wired through dist/js/indigokit.js

Try the keyboard: Tab through the brand link, both icon buttons, and the user area — each shows a visible indigo focus ring.
